# ADR0013：调试控制台与台架输出隔离

状态：ACCEPTED_IMPLEMENTATION_DIRECTION。日期：2026-10-14。基线077d0bf。

## 单向工具依赖

chili_crane_commissioning为独立第8个ROS工具包，stdlib HTTP/本地Web+rclpy。
仅工具依赖core/control/hardware/perception接口，production不得反向依赖或默认启动console。
默认127.0.0.1；非loopback需显式CLI选项，不能因调试便利自动暴露网络。
同源检查、会话token、body/resource bounds、append-only记录和有限操作；HTTP入口不接受任意shell/ROS topic/设备地址。
人工录入数据与实际设备readback来源分列，不宣称电压或FIELD证据已经实测。

## 模拟与台架分离

模拟遥控只发布SOURCE_SIMULATED RemoteControlState，固定隔离commissioning/simulation namespace。
Y左右/Z上下/G开关与STOP支持按下/释放、pointercancel/blur/disconnect/有限心跳lease超时release。
X DO没有确认映射，不猜造输出。模拟state经既有仲裁纯逻辑产生shadow expected command，绝不写真实DO。
台架页醒目ISOLATED BENCH ONLY，默认disabled；物理开启只来自显式启动参数+独立bench配置和现场确认，
HTTP请求不能设置gate或凭证。复用BenchOutputGate/Adam6052Driver/pulse_once/request_to_do与exclusive session。
FSV/WDT/OFF/独占/automatic=false必须全部满足；DO0..5固定既有语义，6/7保留不提供按钮。
单通道、1ms < pulse <=1000ms、写前OFF/active readback/结束OFF readback，异常finally OFF；失联不能伪造OFF，
记录OFF失败并保持恢复锁，设备WDT仍必须经真实验证。软STOP不能替代物理急停/硬接安全链。

## 黑匣子与验收

manifest扩展兼容旧字段，events/operator_actions/bench_measurements JSONL append-only；
每事件有wall/ROS/monotonic、run/task/cycle/binding、exact git SHA/config hash/source和old/new/reason。
state_only与event_debug录制profile分开，高带宽点云不默认无限录制；FIELD容量/轮转尚未知保持NOT_CONFIGURED。
UI/SIL/软件readback mock通过不升级BENCH_DO_WRITE/VOLTAGE、更不升级电机方向/限位/FULL_AUTO。
本轮不连接真实ADAM/电机，BENCH_DO_STATUS=NOT_RUN。软件测试可以使用假transport验证所有门禁/异常清理。
