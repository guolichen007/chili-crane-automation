## 已回传事实

两 ER1：TimeSyncMode=0x02，TimeSyncStatus=0x01，FrameSync=0x01。
PTP：E2E / L2，domain=0，GM=042b58.fffe.2d10a3，PHC=/dev/ptp0。
currentUtcOffset=37，currentUtcOffsetValid=0，ptpTimescale=1，
timeTraceable=0，timeSource=INTERNAL_OSCILLATOR。

双雷达 interclock P95 约 1us，mid_delta P95 约 0.95us，
scan phase aligned，overlap 约 1.0。以上是用户回传近似统计，
本轮不虚构采样时长、样本数、bag hash 或正式可追溯认证。

DUAL_ER1_RELATIVE_TIME_SYNC=PASS
HOST_UTC_RELATION=LOCAL_VERIFIED_NOT_PRODUCTION_TRACEABLE

currentUtcOffsetValid=0 不代表 PTP clock 同步失败：
相对同步、扫描相位、UTC 尺度关系和生产可追溯性是不同事实。
37 秒可保存为 LOCAL_VERIFIED 配置；不能凭此自动进入 production VALID。
运行时仍必须持续读新鲜状态，TimesyncStatus 非成功或超时立即降级。

## 关闭旧假设

ts_first_point=true 时 cloud header 是 frame first-point time，
receive 晚于 frame start 是正常扫描和传输过程。
应分别比较 frame_start / frame_mid / frame_end / receive；
禁止用 37 - observed_header_host_offset 推导 0.12 秒补偿。
固定 rs_driver 原始时间不变，不减 37、不补任何猜测 latency。
