# 2026-10-10 桌面控制硬件联调收口

来源为用户提供的收口报告与硬件调试上下文；本文仅提炼已核实技术事实，不包含设备登录材料。以下 PASS 为交接报告结论，不代表本轮重新执行实机测试。

## 验证范围

- Ubuntu 22.04.5；控制接口 enp4s0，ADAM-CONTROL，10.0.0.10/24，无网关、无 DNS、never-default。办公接口 eno1 保持独立。
- ADAM-6052：10.0.0.1:502，Unit ID 1，8DI/8DO；8DI 读取、DI0 实体闭环通过。仅 DO0 完成 OFF→ON→OFF 软件和电气闭环；其余 DO 未逐路电气验收。
- ADAM-6251：10.0.0.2:502，Unit ID 1，16DI；16/16 ACTIVATED 和 RELEASED 物理闭环通过。
- 控制拓扑：Ubuntu→6251 第二 RJ45→6052；双设备只读 20/20 通过。
- 6052 Host Idle Timeout=5s，Communication WDT=ENABLED，P2P/GCL WDT=DISABLED，DO0..7 FSV=LOW/OFF。
- PROGRAM_LOSS_FAILSAFE、PHYSICAL_NETWORK_LOSS_FAILSAFE、RECONNECT_SAFE、POWER_CYCLE_SAFE、WDT_REPEATABILITY 在桌面交接报告中均为 PASS。
- 上述仅为桌面 I/O fail-safe 验收，不是完整行车现场安全认证。历史未配 WDT 时失联保持 ON；最终配置后自动 OFF，重连不恢复旧 ON。
- 曾出现的网络异常经人工复核为 RJ45 未插紧，不能记为设备网络栈缺陷。

## 拉绳事实

稳定串口 `/dev/serial/by-id/usb-WCH.CN_USB_Quad_Serial_BD89B1ABCD-if06`；9600 8N1，Slave 1，FC03，寄存器 0x0000，2 registers，uint32 高字/高字节先行（已验证报文）。

RAW 模数 409600 为实测数据强支持值，尚未声明厂家型号完全确认。409592→2 展开 +10；7→409599 展开 -8。拉出 unwrapped 增大，回收减小。

桌面候选 COUNTS_PER_MM=18.162，MM_PER_COUNT≈0.05506，R²=0.999938。只属于 DEVELOPMENT_ONLY / NOT_PRODUCTION_CALIBRATION；安装零点、范围和比例需现场重标。

## 必须保持

- 6251 失联 DI_VALID=false，不转成全零；6052 失联 STOP。
- 所有运动 DO 默认 OFF，不继承旧命令。
- FINAL_Y_CALIBRATION=DEFERRED_TO_INSTALLATION。
- REAL_CRANE_ACTUATION_TEST=NOT_EXECUTED。
- 原始测试数据由现场保留；本仓库不包含调试认证信息。
